# Changelog

## 1.0.1 — Public prerelease

- Rename the local TabNest project to NestoraTabs to distinguish it from existing same-name products.
- Replace the old icon with newly drawn geometric artwork and retain a reproducible generator/provenance record.
- Add an opt-in support dialog with local, non-payable WeChat/Alipay placeholders and a user-supplied Polygon address. No wallet/payment API or additional permissions.
- Fix duplicate opening while a previously opened tab is still navigating by checking pendingUrl before url.
- Add mock and actual Chromium regression checks, real synthetic-data screenshots, bilingual documentation and explicit prerelease/source-provenance disclosures.
- Preserve the existing storage schema, features and original MIT attribution. No cloud service, analytics, ads or paid restrictions.

## 1.0.0 — Local TabNest baseline

Original supplied source, unpacked extension and ZIP remain preserved locally. No claim is made that this baseline was previously released publicly.
