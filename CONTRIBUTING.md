# Contributing

Issues and Pull Requests are welcome. Keep changes focused and preserve existing functionality. Do not include browsing history, backups, real profile data, secrets or payment logs. Use synthetic fixtures. Do not add permissions or remote services without a documented need.

No build or dependencies are required. Run each tests/*.test.js file with Node and node --check on runtime JS. Complete MANUAL_TEST_CHECKLIST.md in a real Chrome profile, including upgrade persistence, before release. Never claim mock tests as browser verification.

Include source and redistribution rights for every added asset. Retain existing notices. Report security issues without publishing exploitable private data; do not attach credentials to Issues.
